# الصناديق السرية

صفحة للطلاب فيها عشرة صناديق: يكتب الطالب اسمه الثلاثي، ثم يفتح الصناديق ليكتشف ما خبّأه له المعلم فيها، ويقرأ كل صندوق مدة محددة (10 ثوانٍ افتراضياً) قبل أن ينتقل إلى غيره.

- صفحة الطلاب: https://abdullah2006adi.github.io/sanadeeq/
- لوحة المعلم: https://abdullah2006adi.github.io/sanadeeq/admin.html

## الملفات

- `index.html` صفحة الطلاب.
- `admin.html` لوحة المعلم: تعديل العبارات والصور، واختيار صورة الصناديق أو إضافة صورة جديدة، ثم النشر بضغطة واحدة.
- `config.json` المحتوى المنشور حالياً (تكتبه لوحة المعلم).
- `boards/` صور الصناديق.
- `media/` الصور المخبّأة داخل الصناديق.
